# Правки на согласование

Предложения по боту «Твой карьерный навигатор», которые ещё **не внедрены**. После решения по пункту
отметьте его: ✅ принять · ✏️ принять с изменениями · ❌ отклонить.

Обновлено: 26.09.2026

---

## 1. Ответ на текст после финала

**Статус:** на согласовании

**Проблема.** Если после финала человек что-то пишет в чат, бот молчит: анкета завершена, а
сценарий ждёт только кнопку «Открыть мой профиль». По критерию UX «нет тупиков» это минус.

**Предлагаем** отвечать одной строкой:
> Твой профиль уже готов 🙌 Нажми «Открыть мой профиль», чтобы посмотреть его, или /start, чтобы заполнить заново.

**Решение:** ☐

## 2. Личный кабинет после финала (вместо тупика на карточке профиля)

**Статус:** на согласовании

**Проблема.** После «Открыть мой профиль» дальше делать нечего; повторное нажатие присылает
ещё одну копию карточки. Трек при этом прямо про «отслеживать статус заявлений, узнавать о мерах
поддержки» — у нас этого нет.

**Предлагаем** — под карточкой профиля кнопки (карточка обновляется на месте, без дублей):

| Кнопка | Что делает | Зачем |
|---|---|---|
| 📊 Статус профиля | Создан → Подтверждён → Передан в центр занятости / «Работу России» → Просмотрен работодателем (эмуляция, декларируем в README) | «отслеживать статус» из задания трека |
| 🏛 Меры поддержки | 3–5 реальных программ для молодёжи со ссылками на первоисточники | «узнавать о мерах поддержки» из задания трека |
| ✏️ Изменить ответ | выбрать поле → вопрос заново → назад в карточку | профиль живой, а не одноразовый |
| 🔄 Заполнить заново | = /start | — |

**Архитектура:**
- готовый профиль хранится отдельно от сессии анкеты (по пользователю) — кабинет работает всегда,
  а не только 7 дней жизни сценария;
- кабинет — отдельный обработчик кнопок вне сценария анкеты;
- правка поля — мини-сценарий из одного вопроса, переиспользует существующие тексты вопросов;
- команда `/profile` в меню бота;
- любой текст после финала — ответ с кнопкой кабинета (закрывает п. 1).

**Мини-приложение — отказались (26.09).** Остаёмся в чате: проще для пользователя, и положение
(стр. 15) прямо относит к сценариям чат-бота последовательные вопросы, выбор из вариантов,
персональный результат, проверку статуса и напоминания — это ровно наш продукт. На защите подаём
как осознанное решение.

**Бонус +0,15 закрываем возможностями чата MAX:** запрос геопозиции (уже есть), кнопка
«Поделиться контактом» на шаге связи с экспертами, уведомления о смене статуса профиля в чат.

**Решение:** ☐ делаем кабинет в чате · ☐ оставить как есть
